# About the game Collect and Discard
  Collect and Discard is an educational point-and-click game designed to raise awareness about recycling and the importance of properly sorting waste.
  The game mechanics were developed specifically for students at ASSARTE (Associação Artesanal do Excepcional de Ponta Grossa), an institution that supports individuals with intellectual disabilities, ages 16 to 45.
  This game was a project for the Software Engineering 2025/1 course, taught by Dr. Eliana Claudia Mayumi Ishikawa. The main goal was to apply the Scrum agile development methodology, providing students with practical experience in modern software development techniques.
  
# Sobre o jogo Colete e Descarte
  Se trata de um jogo point-and-click de teor educacional voltado para a concientização sobre reciclagem e a importância da separação de lixos. 
  As mecânicas foi pensadas e projetadas tendo em mente como público alvo os estudantes matrículados na ASSARTE (Associação Artesanal do Excepcional de Ponta Grossa), cuja é uma instituição que atende portadores de necessidades educativas especiais da área de deficiência mental na faixa etária de 16 a 45 anos.
  O jogo foi o resultado de um projeto desenvolvido para o curso de Engenharia de Software 2025/1, ministrado pela Dra. Eliana Claudia Mayumi Ishikawa. Seu objetivo foi a aplicação da metodologia de desenvolvimento ágil Scrum na prática, a fim de fundamentar as boas práticas de desenvolvimento de software e complementar ainda mais na formação dos alunos com uma experiência prática de técnicas atuais utilizadas no mundo da tecnologia.
